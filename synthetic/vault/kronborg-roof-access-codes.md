# kronborg — roof access, codes

the hatch locks from the inside. key with the day shift. electronic lock added five months before he died.

who could open that door on 2025-03-04:

- francisco (day key)
- bernardo (on shift)
- marcellus (on shift)
- facilities, whoever was carrying the master that month
- anyone who was told the code and wrote it down

code changes monthly. last change before that night was 2025-03-03. so the code was one day old, which is the safest a code ever is, which is the part that bothers me.

polonius signed off the install. claudius was not chief executive yet but he was in the building most days. sigrid would know who asked for the lock and why — she was still in the office then. #access
